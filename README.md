Локальный поисковый ассистент. Ищет в интернете, скрейпит страницы и отвечает через локальную LLM — без облаков, без API-ключей.

---

## Как работает

```
Вопрос → DuckDuckGo (5 результатов) → скрейпинг топ-3 URL (параллельно) → Ollama (llama3.1:8b) → ответ со ссылками
```

---

## Требования

- Python 3.10+
- [Ollama](https://ollama.com) установлен и запущен
- Модель `llama3.1:8b` загружена

---

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/CRASHTOOLS/moleAI
cd moleAI

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Установить Ollama и загрузить модель
ollama pull llama3.1:8b
```

## Запуск

```bash
python main.py
```

```
mole> кто такой Линус Торвальдс?
mole> последние новости о Python 3.13
mole> q   ← выход
```

---

## Зависимости

| Пакет | Назначение |
|---|---|
| `requests` | HTTP-запросы к сайтам |
| `duckduckgo-search` | Поиск без API-ключа |
| `beautifulsoup4` | Парсинг HTML |
| `ollama` | Общение с локальной LLM |

---

## Настройка

Модель меняется в начале `mole.py`:

```python
MODEL = "llama3.1:8b"  # любая модель из ollama list
```
